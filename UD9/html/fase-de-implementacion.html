PROG - UD 9: Manipulación de Datos Almacenados en Ficheros de Texto

Fase de Implementación

Descripción

En esta fase, cada miembro del Equipo de Desarrollo se encargará de implementar los diferentes componentes de la aplicación basándose en los Diseños UML elaborados en la Fase de Diseño.

Al final de esta fase se obtendrán los siguientes componentes que se integrarán para desarrollar la aplicación:

  • Modelo de Datos
  • API - Gestión Persistencia
  • API - Interfaz de Usuario
  • Aplicación de Gestión de Matriculación de Alumnos
  • Documentación - Manual de Usuario

Modelo de Datos

Basado en el Diagrama de Clases elaborado junto al resto del Equipo de Desarrollo, implementa los diferentes componentes del Modelo de Datos en una Biblioteca de Clases.

Evaluación del Modelo de Datos

La evaluación del Modelo de Datos tendrá como referente los criterios de evaluación asociados al Resultado de Aprendizaje 4 y 7 del módulo de Programación recogidos en la normativa vigente de la etapa educativa.
