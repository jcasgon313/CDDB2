Proyecto - Gestión de Alumnos

Descripción del Proyecto

Desde que comenzó el curso te has ido adentrando en los diferentes aspectos relacionados con Programación, Entornos de Desarrollo y los diferentes módulos que componen este primer curso del Ciclo de Grado Superior de Desarrollo de Aplicaciones Multiplataforma.  

En este Proyecto se trata de incorporar todos los aprendizajes adquiridos en el Desarrollo de Software.

El Ciclo de Desarrollo de Software se divide en una serie de fases que según las diferentes Metodologías de Desarrollo de Software se emplean de diferentes formas para obtener el Producto Final, la Aplicación.

Para este proyecto vas a emplear, junto con tus compañer@s, una de las Metodologías Ágiles más empleadas en el sector tecnológico, Scrum, de manera que en equipos se establecerán los diferentes diseños y se tomarán las decisiones de implementación de los diferentes componentes.

El Proyecto seguirá las siguientes fases para desarrollar la aplicación:

  • Análisis: Consistirá en estudiar el caso propuesto que se facilita en el siguiente apartado.
  • Diseño: Empleo de herramientas CASE para confeccionar los diferentes Diagramas UML.
  • Implementación: Codificación de los diferentes componentes según el diseño realizado e integración en la Aplicación.
  • Documentación: Elaboración de la Documentación Técnica y Manual de Usuario de la Aplicación

Fase de Análisis

Descripción

Se requiere desarrollar un programa que permita gestionar el Proceso de Matriculación de Alumnos en diferentes Asignaturas.

El Analista Funcional, tras las diferentes entrevistas mantenidas con el cliente, elabora un informe que traslada al Equipo de Desarrollo.

Análisis

Dentro del Ciclo de Desarrollo de Software, esta fase, el Análisis es la más importante de todas, ya que en ella obtenemos la siguiente información que será necesaria para generar la aplicación:

  1. Necesidades del Cliente.
  2. Funcionalidades y Requisitos de la Aplicación.
  3. Datos que se van a gestionar.
  4. Interfaz de Usuario que se empleará.
  5. Forma en la que se almacenarán los datos (Persistencia)
